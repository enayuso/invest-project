## 1. 연결 확인 (1분)

`005930 현재가랑 오늘 등락률 알려줘`

- 기대: 도구를 실제로 호출함 · 삼성전자/KOSPI 확인 · 현재가를 "장중/현재가"로 표현 · 등락률이 퍼센트(예: 3.6%)
- 실패 신호: 도구 호출 없이 기억으로 답함 · "종가"라고 부름 · 등락률이 0.03 같은 100배 작은 값

순서대로: `036540` → `348080` → `379800`

- 기대: 결론·확신도·핵심근거 3개(수치 괄호 인용)·틀릴 조건 2개·확인하지 못한 것·한 줄 요약·고지문 전부 있음 · 결론 전에 점검 결과 한 줄

- **2(전체 분석) —**: 아직 안 함.

### 1차 시험에서 발견한 결함 — ✅ 전부 수정·검증 완료 (테스트 41개)
1. ✅ **에러 메시지가 프로토콜 경계에서 사라짐** (3-7에서 발견, 최우선): `999999`에 "Error executing tool resolve_ticker"만 나왔고 `StaleDataError`도 같은 문장으로 뭉개져 대본 규칙 5가 작동할 수 없었다. SDK의 `ToolError` 통과 경로로 수정. 3단계 검증이 도구를 **파이썬 함수로 직접 호출**해서 못 잡았던 결함 — **이후 검증은 반드시 실제 MCP 클라이언트(stdio)를 거친다.**
   - 후속: 처음 수정은 도메인 에러를 `(ValueError, RuntimeError)`로 잡아서 **pandas 버그(`ValueError`)·`NotImplementedError`까지 데이터 상태로 위장**됐다. 전용 기반 클래스 `AdvisorError`로 좁혀서 버그는 `내부 오류:`로 구분되게 함.
2. ✅ **1억 미만 금액이 원 단위로 표시** (3-6에서 발견): `-31,003,660원` → `-0.31억원`.
3. ✅ 경계 결함: 9,999.96억원이 `10000.0억원`으로 표시되던 것 → 단위를 반올림 **후** 결정해서 `1.0조원`.
4. ✅ `format_pct` 주석이 100배 버그 원인을 거꾸로 적어놨던 것 정정.

### 알려진 잠재 결함 — 6단계(다듬기)로 이월
- `indicators.py`의 `except Exception:`이 지표 하나 실패 시 `null`+`missing`으로 처리한다. 숨기진 않지만 **"과거 데이터 부족"과 "stockstats 버그"를 구분하지 못한다** — 예컨대 라이브러리 업데이트로 컬럼명이 바뀌면 그 지표가 영원히 "데이터 없음"으로 보이고 아무도 모른다. 신규상장 종목은 `sma_120`이 정당하게 비므로 더 눈에 안 띈다. **2026-09-21 기준 005930·379800 모두 `missing: []`로 현재 발동 없음.** 필드별 사유 + 필요 봉 수 사전검사로 구분하는 방향.
